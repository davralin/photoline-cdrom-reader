# Changelog

## 1.0.0

- First release of the local PhotoLine catalog reader.
- County, school, class, people, and class-photo browsing.
- Global normalized substring search with a constrained, clearly labelled typo fallback.
- Linux and Windows amd64 release binaries.
- Minimal read-only GHCR container image for Linux amd64 and arm64.
- Synthetic screenshot only; no catalog data or original photos are distributed.
